## Goal

Isolate all Blob Storage access behind the port **`IBaeDocumentStore`**: create-only upload under a backend-generated name, streamed read, best-effort delete, and validation that a stored blob URL belongs to the configured account and container.

## Context (read first)

- API spec DEC-13, DEC-24 (points 1, 2, 7, 8), §5.4 rules 3–5, §7.2 rules 3–4, EXT-02, §9 (`IBaeDocumentStore` offers create-only upload, `OpenReadAsync`, delete), OPEN-11, §6.1 `Storage:*`; `klesia_api/CLAUDE.md` *Documents*.
- Packages: `Azure.Storage.Blobs`, `Azure.Identity` (versions read from NuGet at implementation time, pinned in `Directory.Packages.props`).

## Scope

- **In:** port, adapter, `DefaultAzureCredential` client registration, unit tests of pure logic (naming, URL validation), fake for tests.
- **Out:** endpoints, retries beyond the SDK defaults.

## Plan of actions

1. Application port:
   - `Task<Uri> UploadAsync(Guid ownerOid, Stream pdf, CancellationToken ct)` → returns the blob URL **without SAS/query**; name `{oid}/{Guid.NewGuid()}.pdf` generated inside the adapter; content type `application/pdf`; **create-only** (`BlobRequestConditions { IfNoneMatch = ETag.All }`); a conflict is an error.
   - `Task<Stream> OpenReadAsync(Uri blobUrl, CancellationToken ct)` → a stream that reads from the service (`BlobClient.OpenReadAsync` or `DownloadStreamingAsync`), never buffering the whole file; exposes length if available (return a small result type with `Stream` and `long? Length`).
   - `Task DeleteAsync(Uri blobUrl, CancellationToken ct)` → best effort, swallow-and-log is the caller's choice (adapter throws).
   - `bool IsOwnedLocation(Uri blobUrl)` (or a separate validator) → true only for `https`, host and container equal to configuration, no query, no fragment.
   - Distinct exceptions: `DocumentNotFoundException` (404 from storage), `DocumentStoreUnavailableException` (network/5xx/timeouts) — so callers can map `500` vs `503`.
2. Infrastructure: `BlobServiceClient(new Uri(Storage:BlobServiceUri), new DefaultAzureCredential())` singleton; container client from `Storage:ContainerName`; no account key, connection string or SAS anywhere.
3. Logging: never log blob URLs or names; log operation + outcome only.
4. Test fake `InMemoryBaeDocumentStore` in `tests/IntegrationTests/Fakes` (configurable failures: unavailable, not found), and unit tests for name format and `IsOwnedLocation` (other account, other container, `http`, query string, path traversal `..`).

## Acceptance criteria

- [ ] Port has no Azure type; adapter uses managed identity only.
- [ ] Create-only upload; generated names `{oid}/{guid}.pdf`.
- [ ] Streamed read; no whole-file buffer; no disk write.
- [ ] URL validation rejects every foreign/malformed case.
- [ ] Unit tests pass; packages pinned centrally.
