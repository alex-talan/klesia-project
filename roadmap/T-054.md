## Goal

Provide `validatePdfFile(file, maxBytes)` implementing the preliminary client checks of NEW-04 (the backend validates the real content).

## Context (read first)

- Webapp spec NEW-04, §3.2 (bytes), AC-13; architecture plan §9.6.

## Scope

- **In:** `src/utils/pdf.ts`, `tests/unit/utils/pdf.spec.ts`.
- **Out:** French messages (T-066).

## Plan of actions

1. Rules: exactly one file (caller passes one); name ends with `.pdf` (case-insensitive); if `file.type` is non-empty it must be `application/pdf`; `file.size <= maxBytes`; `file.size > 0`.
2. Result: `{ ok: true }` | `{ ok: false, reason: 'type' | 'size' | 'empty' }`.
3. No reading of the content, no base64.
4. Tests: valid; `.PDF`; `.txt`; `application/octet-stream` with `.pdf`; empty type with `.pdf` OK; size = limit OK; limit + 1 → size; size 0.

## Acceptance criteria
