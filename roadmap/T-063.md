## Goal

Start the application safely: validate the build configuration, initialise authentication, render nothing protected before sign-in, show French configuration/authentication errors, and render the header with the user's name and `/assets/user_logo.png`.

## Context (read first)

- Webapp spec §3.1 (safe French configuration error), AUTH-01, AUTH-04, AUTH-05, UI-01, UI-05, UI-06; AC-01, AC-02, AC-32, AC-35; mockup `main.png` (header placement).

## Scope

- **In:** startup sequence in `main.ts`/`App.vue` (configuration → `initAuth` → authenticated shell placeholder for the list and the "Nouvelle demande" button area), `AppHeader.vue`, French messages for configuration error ("La configuration de l'application est incomplète…") and authentication error, component tests `tests/components/App.spec.ts`, `tests/components/AppHeader.spec.ts`.
- **Out:** list (T-064), modal (T-066), real-time wiring (T-067).

## Plan of actions

1. `main.ts`: `loadEnvironment()`; if invalid → mount a minimal error view (French, no variable values) and **do not** initialise MSAL or call any API (AC-35).
2. `App.vue`: call `initAuth()`; while redirecting → show nothing protected (optionally "Connexion en cours…"); on error → French authentication error state with no loop (AUTH-04); on success → shell (header + two-column main area of UI-01).
3. `AppHeader.vue`: top-right user name (from `authService.getDisplayName(fallbackUserName)`) + `<img src="/assets/user_logo.png" alt="">` (decorative or with an accessible label — choose and justify); no profile photo.
4. Layout per UI-01 and `main.png`: header, left list panel, right column with the "Nouvelle demande" action aligned with the panel top (button placeholder wired in T-066/T-067).
5. Tests: AC-01 (unauthenticated → loginRedirect, no protected UI), AC-35 (missing variable → French error, MSAL not initialised, no fetch), AC-32 (header name order with the three claim situations), AC-02 (name and icon shown when authenticated).

## Acceptance criteria

- [ ] No protected data rendered before authentication.
