## Goal

Create a minimal, runnable `Program.cs` and the per-layer registration entry points that every later task extends, with no business route yet.

## Context (read first)

- Architecture plan §6.1 (WebApi = transport + composition root only), AP-03, AP-14.
- API spec §4.1 (OpenAPI document anonymous in Development only), §9 (structure), `klesia_api/CLAUDE.md` §2, §5.
- Ports: `http://localhost:5180`, `https://localhost:7180` (contract `servers`, `Properties/launchSettings.json`).

## Scope

- **In:** `Program.cs`, `Application/DependencyInjection.cs` (`AddApplication`), `Infrastructure/DependencyInjection.cs` (`AddInfrastructure(IConfiguration)`), controllers registration, OpenAPI (`Microsoft.AspNetCore.OpenApi`) mapped in Development only, `public partial class Program` for tests.
- **Out:** authentication, CORS, error handling, routes (later tasks).

## Plan of actions

1. `Program.cs`: `WebApplication.CreateBuilder`; add `appsettings.Local.json` as an optional source **after** the environment file (precedence of §6.1: json → environment json → Local → environment variables — make sure environment variables still win, i.e. re-add them after `Local` or add `Local` before the env-var provider).
2. Call `AddKlesiaOptions` (T-009), `AddApplication()`, `AddInfrastructure(configuration)`, `AddControllers()` with `System.Text.Json` defaults (no global naming policy: JSON names are declared on contract records, DEC-21).
3. `AddOpenApi()`; `MapOpenApi()` only when `IsDevelopment()`; the document route is the default `/openapi/v1.json` (used by `check-contract --actual`).
4. `app.MapControllers()`; no route yet besides OpenAPI in Development.
5. Add `public partial class Program;` at the end for `WebApplicationFactory`.
6. Verify layer references: WebApi → Application, Infrastructure; Infrastructure → Application, Domain; Application → Domain; Domain → none.
7. `dotnet run --project src/WebApi` with placeholder settings must **fail** with the T-009 message; with valid fake values in environment variables it must start.
