## Context

- DEC-14: Azure SQL Database, passwordless (`Authentication=Active Directory Default`, DEC-06). The runtime identity is a database user created `FROM EXTERNAL PROVIDER` with the privileges of §6.2; schema deployment uses a distinct, more privileged principal (HOST-11).
- OPEN-07 (b)–(e) are DSI decisions.

## Questions

1. Server name, database name, service tier, region, backup/retention policy.
2. Entra administrator of the logical server; is Microsoft Entra-only authentication enabled?
3. Who creates the database users (runtime identity, deployment principal, developers) and when?
4. TLS: confirm `Encrypt=True`, `TrustServerCertificate=False`.

## Recommendation

Entra-only authentication enabled; an Entra group as server admin; database users created by the DSI operator with the script of `klesia_api/docs/local-development.md` §2.
