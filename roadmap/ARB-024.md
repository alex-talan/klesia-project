## Context

- Webapp spec §2 and architecture plan §5: Node.js **26 LTS**, recorded in `.nvmrc` and `package.json` `engines`.
- A previous local check ran on Node 24 (workspace notes). GitHub-hosted runners can install Node 26 with `actions/setup-node`; the Static Web Apps build image (if the SWA action builds) may lag behind.

## Question

Confirm Node 26 LTS everywhere, and whether the SWA deployment must use a pre-built `dist/` (build in the workflow with Node 26, upload only) rather than the SWA build image.

## Provisional default (non-blocking)

Node 26 LTS in `.nvmrc`/`engines` (`>=26 <27`); CI builds with `actions/setup-node` reading `.nvmrc`; the delivery pipeline deploys the pre-built `dist/` without rebuilding.
