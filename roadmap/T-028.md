## Goal

Implement operation `getDemandDocument`: after token, scope and allowlist checks, stream the BAE PDF of one of the caller's own demands from the private container, with the specified headers; identical `404` for a missing or foreign demand.

## Context (read first)

- API spec §5.4 (API-04, rules 1–7, status codes), DEC-24, §5.2; contract `getDemandDocument`; AT-19, AT-51, AT-52, AT-53, AT-54, AT-58, AT-59; `klesia_api/CLAUDE.md` *Documents*.

## Scope

- **In:** `DemandService.OpenDocumentAsync(oid, demandId, ct)`, controller action `[HttpGet("api/v1/demands/{demand_id:int:min(1)}/bae")]`, tests.
- **Out:** Range requests (not supported), caching.

## Plan of actions

1. Route constraint: `demand_id` positive integer; any other value (`abc`, `0`, `-1`) → `404` problem+json (ensure the status-code-pages problem body from T-015 applies and the fallback policy does not turn it into `401` for an authenticated caller — the request is authenticated first; document the observed order in tests).
2. Use case: resolve user (T-021) → `GetOwnedBaeLinkAsync(demandId, user.Id)` → `null` → `NotFound` (same problem for both causes; storage **not** called).
3. Validate the stored URL with `IsOwnedLocation` → invalid → sanitised `500` (AT-19), value never logged.
4. `OpenReadAsync` → `DocumentNotFoundException` → sanitised `500` (log demand id only); `DocumentStoreUnavailableException` before first byte → `503` problem.
5. Response: `200`, `Content-Type: application/pdf`, `Content-Disposition: inline; filename="bae-{demand_id}.pdf"`, `Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff`, `Content-Length` when known; copy the stream to `Response.Body` with `HttpContext.RequestAborted` (e.g., `Results.Stream`/`FileStreamResult` with `EnableRangeProcessing = false`). Failure after the first byte: abort and log without user data.
6. Document available whatever the status (`pending`, `ok`, `fail`).
7. Tests (fakes): AT-51 exact bytes and headers; AT-52 other user's id, unknown id, `abc` → identical `404` bodies (except `traceId`), store not called for the first two; AT-53 `401`/`403` and store not called; AT-54 missing blob `500` then unavailable `503`, no storage detail; AT-19 foreign/`http`/query URL → `500`, nothing streamed; AT-58 streaming double: large stream (size `Upload:MaxPdfSizeMb`) read in chunks, no `MemoryStream` of the full size (assert the fake stream is read progressively), cancellation stops reading; AT-59 preflight allowed.
