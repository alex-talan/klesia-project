## Goal

Define the shared CSS variables of UI-04 and the global base styles (page background, typography colour, button styles with visible hover/focus/disabled states, desktop layout ≥ 1024 px) used by every component.

## Context (read first)

- Webapp spec UI-01, UI-03, UI-04 (token table), UI-05, UI-06, UI-07 (button style: 12 px radius, white italic bold text), §5; mockups `maquettes/main.png`, `modal.png`, `states.png` (**inspect them**).

## Scope

- **In:** `src/styles/tokens.css` (or equivalent) with the 12 tokens as CSS custom properties, `src/styles/base.css`, button classes (primary, cancel), focus-visible outline; imported once in `main.ts`.
- **Out:** component-specific layout.

## Plan of actions

1. Variables: `--color-background: #C6CBDA`, `--color-heading: #1A2F6B`, `--color-primary: #1A2F6B`, `--color-cancel: #536390`, `--color-button-text: #FFFFFF`, `--color-surface: #FFFFFF`, `--color-border: #1A2F6B`, `--color-input-text: #1A2F6B`, `--color-link: #1A2F6B`, `--color-status-pending: #FF7A00`, `--color-status-ok: #00B050`, `--color-status-fail: #FF0000` (names free; values exact).
2. Base: body background, font, min-width 1024 px target, no horizontal overflow at target widths.
3. Buttons: primary and cancel styles from the mockups; hover, `:focus-visible` (visible outline not relying on colour alone), `:disabled`; same font weight for status labels (UI-06).
4. A unit test (or a static check) asserting the token values exist in the CSS (prevents accidental changes).
5. Inspect mockups and note spacing/radius values used.
