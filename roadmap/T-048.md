## Goal

Create the single HTTP client layer of the SPA (AP-04): an authenticated request helper that sends the API access token **only** to the API origin, classifies errors by HTTP status, performs one controlled 401 recovery for safe requests, and the `listDemands()` operation.

## Context (read first)

- Webapp spec DEM-01, §8 (error table), AUTH-03, AUTH-06, AC-02, AC-19, AC-24, AC-25, AC-45, AC-49; contract `listDemands`; architecture plan §7.2 (*Error model*, platform non-JSON errors).

## Scope

- **In:** `apiRequest` helper (internal), `ApiError` type (`kind`: `unauthorized`, `forbidden`, `notFound`, `badRequest` (+ `errorKeys`), `payloadTooLarge`, `unsupportedMediaType`, `unprocessable` (+ `errorKeys`), `server`, `network`, `malformed`), `listDemands(): Promise<UserDemands>`, tests `tests/unit/services/demandService.spec.ts`.
- **Out:** create (T-049), document (T-050).

## Plan of actions

1. URL building: `new URL(path, VITE_API_BASE_URL)`; assert the resulting origin equals the API origin before attaching the token (AC-49).
2. Headers: `Authorization: Bearer <access token>`, `Accept` per operation; never log headers/URLs.
3. Status classification: parse `application/problem+json` only to read `errors` **keys** (never `title`/`detail`); non-JSON platform errors (502/503/504) → `server`; fetch rejection/timeout → `network` (use `AbortController` with a reasonable timeout constant).
4. 401 handling for idempotent GETs: call `authService.recoverFromUnauthorized()` once, retry once; never for POST (T-049).
5. `listDemands`: `GET /api/v1/demands`, `Accept: application/json`; on 200 → `parseUserDemands` (malformed → `ApiError('malformed')`).
6. Tests (mock `fetch` and `authService`): AC-02 (token = access token, URL = base + path), AC-19 (403 → forbidden), AC-24 (malformed 200 → malformed), AC-25 (401 → one recovery then success; second 401 → unauthorized, no loop), 5xx/HTML body → server, network → network, `errors` keys extracted, server text never surfaced, console spy shows no token/URL (AC-45 partial), fixtures from contract examples.
