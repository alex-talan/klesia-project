## Goal

Bind every configuration section of API spec §6.1 to a strongly typed options class and **refuse to start** with a clear message when a mandatory value is missing, malformed or still a `<placeholder>` (DEC-04, architecture plan §10.4).

## Context (read first)

- API spec §6.1 (keys, defaults, validation rules), §5.2 (CORS origin rules: no path, HTTPS except loopback, `*` forbidden), DEC-11 (`RequiredScope` = `access_as_user`), DEC-06 (connection string), `docs/local-development.md` §3 ("refuses to start … and says which one").
- Architecture plan §6.1: options live in `Infrastructure/Options` (WebApi-only ones such as `AzureAd`/`Cors` may live in `WebApi`).
- Milestone M1 (T-058) runs without extraction: the Document Intelligence section is validated at startup only once T-065 wires the extraction. The final behaviour (refuse to start when it is missing) is therefore reached at T-065, as API spec §6.1 requires.
- The API host is not composed until T-010; this task tests the options validators and `ValidateOnStart` registrations directly. Host-level startup validation is covered by T-010, avoiding a dependency cycle.

## Scope

- **In:** options classes, validators, registration helpers (`AddValidatedOptions` with `ValidateOnStart`), unit tests.
- **Out:** the consumers (JWT, CORS, repositories…) which come in later tasks.

## Plan of actions

1. Options classes and sections:
   - `AzureAdOptions` (`AzureAd`): `Instance` (default `https://login.microsoftonline.com/`), `TenantId` (GUID), `ClientId` (GUID), `RequiredScope` (non-empty, no spaces, not a URI), `Audiences` (optional list).
   - `CorsOptions` (`Cors`): `AllowedOrigins` (array; each an absolute origin: scheme + host [+ port], no path/query/fragment, `https` required except `http://localhost`/`127.0.0.1`, `*` forbidden; empty array allowed = no cross-origin access).
   - Connection string `KlesiaDb` (non-empty; must not contain `Password=`/`Pwd=` — passwordless, DEC-06).
   - `StorageOptions` (`Storage`): `BlobServiceUri` (absolute `https` URI, no query), `ContainerName` (valid container name).
   - `UploadOptions` (`Upload`): `MaxPdfSizeMb` (integer > 0; expose `MaxPdfSizeBytes` = MB × 1,048,576).
   - `DocumentIntelligenceOptions`: `Endpoint` (https URI), `ModelId` (non-empty), `TimeoutSeconds` (default 120, > 0), `ApiVersion` (optional). **Registered by a separate method** (e.g., `AddDocumentIntelligenceOptions`) that only T-065 calls from `Program.cs` when it wires the extraction: until then the API must start without these values (milestone M1, [roadmap.md](roadmap.md) §8). The validator itself is written and unit-tested here.
   - `ExtractionOptions`: `MaxConcurrency` (default 2, ≥ 1), `QueueCapacity` (default 100, ≥ 1), `StaleAfterMinutes` (default 15, must be > `TimeoutSeconds`/60), `SweepIntervalMinutes` (default 5, ≥ 1).
   - `AzureSignalROptions` (`AzureSignalR`): `Endpoint` (https URI), `HubName` (default and only allowed value `demands`).
2. A shared placeholder rule: a value matching `^<.*>$` (or containing `<` and `>`) is rejected.
3. Implement validation with `IValidateOptions<T>` (no new package; DataAnnotations allowed), registered with `.ValidateOnStart()`. Messages name the key (`AzureAd:TenantId is missing or a placeholder`) and **never echo the value** (it may be sensitive).
4. Provide registration extension methods (e.g., `services.AddKlesiaOptions(configuration)`), called later by the composition root (T-010).
5. Unit tests per options class: valid configuration passes; each missing/placeholder/malformed value fails with the key name; CORS origin cases (`*`, `https://a.b/path`, `http://example.com`, `http://localhost:5173` OK); StaleAfterMinutes ≤ timeout fails.
