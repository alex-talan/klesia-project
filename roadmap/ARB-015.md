## Context

- HOST-04: one **user-assigned** managed identity attached to the web app, selected through `AZURE_CLIENT_ID`; it is the SQL database user, the storage identity (*Storage Blob Data Contributor* on the container), the Document Intelligence identity (*Cognitive Services User*) and the SignalR identity (role per ARB-004).
- OPEN-11 keeps this as an assumption to confirm.

## Question

Does the DSI accept one shared user-assigned identity for all four services, with role scopes as narrow as possible (container scope for storage)?

## Provisional default (non-blocking)

The specification's model. The code uses `DefaultAzureCredential` and works with any identity, so a different decision only changes IaC.
