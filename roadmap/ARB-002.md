## Context

- API `Upload:MaxPdfSizeMb` and webapp `maxPdfSizeMb` must hold the same value (architecture plan §14.1); 1 MB = 1,048,576 bytes.
- 10 MB is **illustrative** (INT-05). The App Service request limits, the platform request timeout (OPEN-08f) and the Document Intelligence model limits (OPEN-09d) must be compatible.
- PDFs travel through the App Service instances in both directions (OPEN-12d).

## Questions

1. What is the business maximum PDF size?
2. Is it compatible with the Document Intelligence limits (size, pages) and with the App Service request limits and timeout?

## Provisional default (non-blocking)

`10` MB in both `Upload:MaxPdfSizeMb` and `public/config/app-config.json`. Every task implements the limit as configuration only, so the settled value needs no code change.

## Impact if settled differently

Configuration change in both applications and in the App Service request limits (T-082); no code change.
