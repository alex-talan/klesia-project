## Goal

Add the database-set UTC creation time used by the recovery sweep (EXT-09) to `dbo.Demand`, exactly as specified (DEC-23).

## Context (read first)

- API spec DEC-23, §3.3 (`dbo.Demand` table: `CreatedAt DATETIME2(6) NOT NULL`, `DF_Demand_CreatedAt DEFAULT SYSUTCDATETIME()`), §3.4 (normative DDL of `Tables/dbo/Demand.sql` and the implementation notes), §3.5, DB-06 naming, HOST-11 backward compatibility.
- Current file: `klesia_api/database/Klesia.Database/Tables/dbo/Demand.sql` (no `CreatedAt`).

## Scope

- **In:** `Tables/dbo/Demand.sql` only.
- **Out:** any other column, index or check; the API code (never returns `CreatedAt`).

## Plan of actions

1. In `Tables/dbo/Demand.sql`, add after `StatusId`:
   `[CreatedAt] DATETIME2(6) NOT NULL CONSTRAINT [DF_Demand_CreatedAt] DEFAULT SYSUTCDATETIME(),`
   matching the §3.4 DDL character for character (formatting may differ, semantics must not).
2. Keep the existing comment on the GK check, the checks, the FKs and both indexes unchanged.
3. Build the project: `dotnet build database/Klesia.Database/Klesia.Database.sqlproj -c Debug` (from `klesia_api/`).
4. Reason about the publish over an existing database: adding a `NOT NULL` column **with a default** is filled for existing rows and is not a data-loss operation (`BlockOnPossibleDataLoss` stays on; `GenerateSmartDefaults` is `False` and is not needed because the default is declared). Record this in the completion record.

## Acceptance criteria

- [ ] `Demand.sql` declares `CreatedAt DATETIME2(6) NOT NULL` with the named default `DF_Demand_CreatedAt` = `SYSUTCDATETIME()`.
