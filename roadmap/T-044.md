## Goal

Apply the contract validator (T-023) to every response produced by the backend integration tests of the five operations, and complete the Level 1 matrix of the `integration-test` skill.

## Context (read first)

- `integration-test` skill Level 1 (full list of AT per group), API spec §10; contract (all operations and responses).

## Scope

- **In:** retrofit assertions in existing tests; add any missing AT case of Level 1; a coverage table in the completion record.
- **Out:** environment-dependent cases (AT-33, AT-35, AT-57, AT-15/16/17/49 → T-076, T-077, T-087).

## Plan of actions

1. For each integration test hitting an operation, call `ContractValidator.AssertResponse(response, operationId)` (status, content type, schema).
2. Add a test per operation asserting that every documented non-2xx produced by the API is `application/problem+json` with `traceId` = `X-Correlation-Id` (AT-21).
3. Cross-check the Level 1 lists (read/authorisation, creation, document, real-time, hosting) and add missing tests.
4. Assert that both `403` causes and the missing-scope `403` give identical bodies (except `traceId`) on each protected operation.
5. Produce the AT coverage table (AT id → test name or *environment-dependent / not run*).

## Acceptance criteria

- [ ] Every backend integration response is validated against the contract.
- [ ] Level 1 AT list fully covered or explicitly marked environment-dependent.
- [ ] `dotnet test` green.
