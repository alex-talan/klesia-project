## Goal

Make `realtimeService.ts` the only module that knows SignalR: one `HubConnection` to `VITE_SIGNALR_HUB_URL` with negotiation, `accessTokenFactory` returning the API access token, `withCredentials: false`, the RT-06 retry policy (also for the initial start), connection-state events, a `demandUpdated` handler that ignores its payload, and clean stop.

## Context (read first)

- Webapp spec RT-01 to RT-08, §6.5 (BE-01 to BE-07), AC-36 to AC-41; architecture plan §7.3.

## Scope

- **In:** service API: `start(onNotification, onStateChange)` → resolves when the first attempt settles (connected or failed) or after 5 s; states `connected | reconnecting | disconnected | unavailable`; `onReconnected` callback; `stop()`; tests with a mocked `@microsoft/signalr`.
- **Out:** list reload orchestration (T-052/T-057), UI.

## Plan of actions

1. `new HubConnectionBuilder().withUrl(hubUrl, { accessTokenFactory: () => authService.getApiAccessToken(), withCredentials: false })` — no `skipNegotiation`, no transport override.
2. `withAutomaticReconnect({ nextRetryDelayInMilliseconds: ctx => [0, 2000, 5000, 10000, 30000][ctx.previousRetryCount] ?? 30000 })` (never `null` → retries forever).
3. Initial `start()` with the same backoff loop on failure (the client does not retry it); a 403 during negotiation → state `unavailable` and stop retrying (RT-02/RT-07); a 401 → one auth recovery path without loop (AUTH-06) then treat as unavailable if it persists.
4. `connection.on('demandUpdated', () => onNotification())` — arguments ignored entirely.
5. `onreconnecting` → `reconnecting`; `onreconnected` → `connected` + callback (reload trigger); `onclose` → `disconnected` or `unavailable`.
6. Logging: `configureLogging(LogLevel.Warning)` (Error in production) and a custom logger that never prints URLs/tokens (or rely on levels that do not print them — verify).
7. `stop()` removes handlers and stops the connection (AC-40).
8. Tests: AC-36 (one connection, URL, factory returns access token not id token, `withCredentials: false`), AC-37 (reconnecting then reconnected → state events and reload callback), AC-38 (negotiate 401/403/network → state unavailable/disconnected, no throw, no loop), AC-39 (payload ignored), AC-40 (stop), AC-41 (log level; console spy).
