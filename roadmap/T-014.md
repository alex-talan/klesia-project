## Goal

Every response carries `X-Correlation-Id`; every request produces one structured log entry (route, outcome/status, duration, correlation id) that respects the redaction rules.

## Context (read first)

- API spec §6.1 (*Logging*: correlation id generated when absent or unsafe), §6.2 (what must never be logged), §5.2 (`traceId` equals `X-Correlation-Id`; CORS exposes it), architecture plan §11.1, §9.5; contract `components.headers.CorrelationId`.

## Scope

- **In:** correlation middleware, request-log middleware (or `UseHttpLogging` configured to log nothing sensitive), console JSON logging, tests.
- **Out:** ProblemDetails `traceId` (T-015), telemetry SDK (ARB-016).

## Plan of actions

1. `CorrelationIdMiddleware` (first in the pipeline): read the incoming `X-Correlation-Id`; accept it only if *safe* (e.g., 1–64 chars of `[A-Za-z0-9-_.]`); otherwise generate a new one (GUID "N"); store it in `HttpContext.TraceIdentifier` and `HttpContext.Items`; add it to the response headers via `OnStarting` (so it is present on every response, including errors and `401`); open a logging scope `CorrelationId`.
2. `RequestLoggingMiddleware`: after the request, log at Information: method, **route template** (not the raw path with ids? — the id is not sensitive, but prefer the template), status code, elapsed ms. Never log headers, query strings, bodies, tokens, file names, GK numbers or URLs of blobs.
3. Configure console logging with the JSON formatter and scopes; keep `Logging` levels of `appsettings.json`.
4. Do **not** use `UseHttpLogging` with request/response headers or bodies.
5. Integration tests (T-012 harness): a response has `X-Correlation-Id`; a safe incoming id is echoed; an unsafe one (too long, CR/LF, spaces) is replaced; the log entry contains route, status, duration and correlation id; the log sink contains no `Authorization` value.

## Acceptance criteria

- [x] `X-Correlation-Id` is registered with `OnStarting`, so it is present across normal and error responses; integration tests cover generated and echoed ids.
- [x] Unsafe incoming ids are replaced; tests cover spaces, control characters and excessive length.
- [x] One structured request log entry records method, route template/outcome, status, elapsed ms and correlation id; redaction tests reject Authorization and GK values.
- [x] Tests pass.
