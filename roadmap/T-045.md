## Goal

Provide the dev-only backend and hub simulator implementing the same contract over the same protocol, so the frontend is developed with no backend and no code path differs from production (SIM-01 to SIM-05).

## Context (read first)

- Webapp spec §2.2 (SIM-01 to SIM-06), §6.5 (BE-01 to BE-07), DEM-03 (fixture PDF, headers), §7.3; contract examples; architecture plan §7.6.

## Scope

- **In:** `tools/dev-simulator/` (Node script, dev dependency `ws` only), npm script `sim`, a small fixture PDF (generated, no personal data), README section (brief, in `tools/dev-simulator/README.md` or the main README in T-073).
- **Out:** token validation (never), any import from `src/`.

## Plan of actions

1. Server on `127.0.0.1` only (port configurable, e.g., 5180 to mirror the API, or another documented port); CORS limited to `http://localhost:5173`; allow headers `Authorization`, `Content-Type`, `X-Requested-With`, `X-SignalR-User-Agent`; expose `X-Correlation-Id`; no credentials.
2. Every API and negotiate request requires a non-empty `Authorization: Bearer` header (never logged) — else `401` problem+json.
3. Routes (contract shapes, problem+json errors, `X-Correlation-Id`):
   - `GET /api/v1/demands` from in-memory fixtures (contract examples, `bae_link` = API path).
   - `GET /api/v1/demands/{id}/bae` → fixture PDF, `application/pdf`, `Cache-Control: private, no-store`, `Content-Disposition: inline`; unknown id → `404`.
   - `POST /api/v1/demands` (multipart: exactly `gk_number`, `bae_file`) → `201` demand `pending`; then N-1 immediately, then after a configurable delay set `ok` (or `fail`) and N-2.
   - `POST /api/v1/notifications/negotiate` → `{ url: ws://127.0.0.1:<port>/client/?hub=demands, accessToken: <random> }`.
4. SignalR JSON hub protocol over WebSocket: handshake `{"protocol":"json","version":1}` + record separator `0x1e`, handshake response `{}`, pings (type 6), invocation `{"type":1,"target":"demandUpdated","arguments":[]}`; accept the connection token (query `access_token`) as issued.
5. Control endpoints (localhost only, e.g., `/__sim/...`): send `demandUpdated` (optional malformed payload), set a demand status, drop all sockets, delay/refuse next negotiate (401/403), fail next GET, next POST error (400 with `errors` keys, 413, 422, 5xx) or delay, complete a pending demand now (`ok`/`fail`) or never, next BAE answer 401/403/404/500/503/delay/non-PDF content type.
6. `npm run sim` script; never part of `dist/` (outside `src/`, not imported).
7. Smoke test by hand: start sim + `npm run dev` with `.env.local` pointing to the sim (record result).
