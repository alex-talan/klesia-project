## Goal

Restore the webapp's required repository-wide `format:check` gate without weakening Prettier or introducing unrelated behavior changes.

## Context (read first)

- `klesia_webapp/package.json` defines `format:check` as `prettier --check .`; the pinned Prettier version is 3.10.1.
- During T-047 verification on 2026-11-24, the command reported 32 committed webapp files as unformatted, including unchanged `src/App.vue` and `src/main.ts`. The two T-047 files pass focused Prettier checks.
- The failure blocks completion of T-047's required full verification. See [T-047](T-047.md).

## Scope

- **In:** identify why the current tracked webapp files fail the configured Prettier check; restore formatting compliance for the affected files while preserving behavior and user intent; rerun the full format gate.
- **Out:** changing or weakening formatter rules merely to silence the check; unrelated functional changes; dependency upgrades unless required and separately approved.

## Plan of actions

1. Compare the effective Prettier configuration, installed version, Git line-ending settings, and representative formatted/unformatted files.
2. Determine the smallest correction that restores consistency with the existing configured style; avoid changing semantics.
3. Format only affected files and inspect the resulting diff for non-formatting changes.
4. Run `npm.cmd run format:check`; also run type-check, lint, tests, build, and audit if implementation changes extend beyond formatting.

## Acceptance criteria
