## Context

- Architecture plan §10.4 lists Local, Dev/Staging and Production. The contract `servers` has a staging and a production placeholder host. `infra/azure-signalr` has `dev` and `prod` parameter files only.
- Each environment needs its own frontend build (`VITE_*` baked at build time), its own API settings, database, storage account (OPEN-12c), SignalR resource and Entra redirect URIs.

## Questions

1. Which environments exist: dev, staging, prod (or dev and prod only)?
2. Azure subscription(s) and resource group(s) per environment; region(s).
3. Naming convention for resources (DSI standard?).
4. Host names of the API and the SPA per environment (feeds CORS, CSP, redirect URIs, contract `servers`).

## Recommendation

Three environments (dev, staging, prod), one resource group per environment, the DSI naming convention.
