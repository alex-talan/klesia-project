## Goal

Add `IDemandRepository.GetOwnedBaeLinkAsync(int demandId, int userId, ct)` that reads the internal blob URL of a demand **filtered on both ids in one query**.

## Context (read first)

- API spec §5.4 rule 2 (*one query that filters on both ids … never read first and compare afterwards*), DEC-24 point 4, AT-52; architecture plan §8.4 (*Document* flow).

## Scope

- **In:** repository method + Dapper SQL + opt-in DB test.
- **Out:** URL validation and streaming (T-028).

## Plan of actions

1. SQL: `SELECT d.BaeLink FROM dbo.Demand AS d WHERE d.Id = @DemandId AND d.UserId = @UserId;` → `string?`.
2. Return `null` when no row (missing or foreign — indistinguishable by design).
3. Never log the returned value.
4. Opt-in DB test: own demand → value; other user's demand → null; unknown id → null.

- [x] `QuerySingleOrDefaultAsync<string?>` returns `null` for missing and foreign demands.
