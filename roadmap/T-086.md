## Goal

Implement HOST-11: on the main branch (and per environment as decided), build, test, publish the API, publish the DACPAC with `SqlPackage` using the deployment principal, deploy to App Service (staging slot first if available), smoke-test `GET /health`, keep the previous version for rollback — authenticated with OIDC, no stored secret.

## Context (read first)

- API spec HOST-11, AT-22, AT-33, §3.5 (publish profile); `docs/deployment-app-service.md` §6; [ARB-017](ARB-017.md), [ARB-011](ARB-011.md), EXT-008.

## Scope

- **In:** deployment workflow reusing CI artifacts (T-011), GitHub environments with approvals per ARB-017, `azure/login` with OIDC (`id-token: write`), `SqlPackage` publish (DACPAC + `Azure.publish.xml` + `/v:Environment=…` from T-085) with an Entra access token for the deployment principal, generated-script artifact for review (data-loss blocking on), App Service deployment (zip deploy to slot), smoke test with retries, swap (if slots), rollback instructions.
- **Out:** infrastructure provisioning (T-080–T-084).

## Plan of actions

1. Workflow triggers per ARB-017 (e.g., push to main → dev; manual approval → staging/prod).
2. Jobs: build/test (or reuse CI) → `dotnet publish src/WebApi -c Release` → artifact.
3. SQL job: `azure/login` (OIDC) → install `SqlPackage` → `/Action:Script` (artifact for review) → `/Action:Publish` with `/AccessToken:` from `az account get-access-token --resource https://database.windows.net/` (no password) → never at API startup.
4. Deploy job (after SQL): `azure/webapps-deploy` to the staging slot (or production if no slot) → smoke `GET https://<host>/health` expecting `200` with retries → slot swap.
5. Rollback: document swap-back or redeploy of the previous artifact.
6. Order guarantee: SQL publish strictly before app deployment; schema backward compatible (HOST-11).

## Acceptance criteria

- [ ] A run deploys to dev successfully with `/health` = `200` (record link).
- [ ] No secret stored (OIDC only); publish script archived.
- [ ] Rollback procedure documented and tested once on dev (or *not run* with reason).
