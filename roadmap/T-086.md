## Goal

Build the SPA once per environment with that environment's public `VITE_*` values, substitute the CSP origins in `staticwebapp.config.json`, run the build gate, and deploy the pre-built `dist/` to the environment's Static Web App with the authentication decided in ARB-018.

## Context (read first)

- Webapp spec §3.1 (values baked at build time; supplied by the pipeline), DEP-01, DEP-02, DEP-04, DEP-05; [ARB-018](ARB-018.md), [ARB-017](ARB-017.md), [ARB-024](ARB-024.md).

## Scope

- **In:** workflow with GitHub environments (variables, not secrets, for `VITE_*` — they are public), CSP origin substitution step (T-068 mechanism) with a post-check (AC-48 test run on the substituted file), `npm ci` + gate + `npm run build`, deployment of `dist/` without rebuilding, `app-config.json` value per environment (ARB-002).
- **Out:** Entra registrations (EXT-001).

## Plan of actions

1. Per environment: set variables `VITE_API_BASE_URL`, `VITE_ENTRA_CLIENT_ID`, `VITE_ENTRA_TENANT_ID`, `VITE_ENTRA_REDIRECT_URI`, `VITE_API_SCOPE`, `VITE_SIGNALR_HUB_URL`, `CSP_API_ORIGIN`, `CSP_SIGNALR_ORIGIN`, `MAX_PDF_SIZE_MB`.
2. Build in production mode (https enforced by T-050); run tests; substitute; verify headers test.
3. Deploy per ARB-018 (OIDC-based or environment-scoped deployment token), `skip_app_build: true` (upload `dist/` only).
4. Smoke test: `GET https://<swa>/`, `/redirect.html` headers (`no-store`, no COOP), `/config/app-config.json` served as JSON.
