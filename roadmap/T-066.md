## Goal

Implement the accessible "Nouvelle demande" dialog: GK number field, "BAE" file chooser with PDF icon and name, "OK" and "Annuler", client validation, in-progress state, French errors, no automatic retry, and emit `submitted` on success.

## Context (read first)

- Webapp spec NEW-01 to NEW-09, §3.2 (upload disabled on configuration error, limit shown in the error), §8 (400/413/415/422/5xx messages), UI-06 (placeholder `GK000000-000000000`, no title bar), AC-09 to AC-17, AC-20, AC-26 to AC-30; mockup `modal.png` (**inspect**).

## Scope

- **In:** the dialog component (opened/closed by the parent), validation wiring, submission through `createDemand`, French messages, focus management, component tests `tests/components/NewDemandModal.spec.ts`.
- **Out:** list reload (none — RT-05), parent orchestration (T-067).

## Plan of actions

1. Dialog: native `<dialog>` with `showModal()` (inert background, focus trap) or an equivalent accessible implementation; focus moves in on open, returns to the "Nouvelle demande" button on close; centred in the page.
2. Content order: label "No. GK :" + input (placeholder `GK000000-000000000`, empty value); button "BAE" opening `<input type="file" accept=".pdf,application/pdf">`; after selection `/assets/pdf_logo.png` + file name; "OK" (primary) and "Annuler" (cancel style). Use "BAE", never "DAE".
3. Validation on OK: `validateGkNumber` (French inline errors: required / format), `validatePdfFile` with `maxPdfSizeBytes` (French errors: type; size including the configured limit in MB). Runtime configuration error → file selection and OK disabled with a French configuration message (AC-20).
4. Submission: OK disabled, in-progress indicator, Annuler and Escape disabled; call `createDemand(normalizedGk, file)` exactly once; success → emit `submitted`, close and reset; failure → keep the modal open with draft intact and show the French message chosen from the error kind and `errors` keys (never server text); no automatic retry.
5. Annuler while idle → close and clear; Escape while idle → close; outside click → nothing.
6. Replacement selection replaces the previous file; nothing is sent on selection; file references cleared on close.
7. Tests: AC-09, AC-10 (via the util), AC-11, AC-12, AC-13, AC-14 (through a mocked service: called with normalised GK and the file), AC-15 (closes, no list call), AC-16, AC-17, AC-20, AC-26, AC-27, AC-28 (double-click → one call), AC-29, AC-30.
