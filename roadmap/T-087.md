## Plan of actions

2. Deploy API and SPA.
3. AT-33: `/health` = `200`, then `GET /api/v1/demands` with a real token = `200`; confirm the pipeline published the DACPAC before the deployment.
4. AT-35: inspect App Service settings (Always On, HTTPS Only, TLS 1.2, Health check, `AZURE_CLIENT_ID`, platform CORS empty).
