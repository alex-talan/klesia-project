# ARB-020 — Data retention and personal data (GDPR)

| Field | Value |
|---|---|

| Subject | Data retention and personal data (GDPR) |

| Blocking | NO |
| Concerning tasks | `T-080`, `T-089` |
| Status | OPEN |

## Context

- PDFs and extracted data contain company and personal data (referrer identity and e-mail, contact details, addresses) — API spec EXT-10, §6.2.
- Nothing deletes demands (DB-09, no `DELETE` grant); blobs live as long as their demand; `bae_link` never expires (DEC-24).
- Storage lifecycle and soft delete are ARB-014.

## Questions

1. Retention period of PDFs, demands and extracted data.
2. Procedure for deletion requests (operator procedure; the API has no delete route and must not get one without a contract change).
3. Need for a data-processing record or DPIA.

## Provisional default (non-blocking)

No automatic deletion; data kept indefinitely until the client decides. Development proceeds; production go-live (T-089) requires a decision.

## Impact if settled differently

Operator procedure and/or storage lifecycle rule (IaC) and possibly a scheduled clean-up job (new task, schema and privilege review since the runtime identity has no `DELETE`).
