## Goal

Check the running SPA (against the simulator) against `maquettes/main.png`, `modal.png` and `states.png`, applying the reconciliation rules of UI-06, and fix visual deviations.

## Context (read first)

- Webapp spec UI-01 to UI-07 (UI-06 reconciliation list), DEM-02, NEW-02; the three mockups (**inspect the images**).

## Scope

- **In:** spacing, alignment, sizes, colours, fonts, focus visibility, accessibility labels; screenshots of each state for the record.
- **Out:** behaviour changes.

## Plan of actions

1. Run `npm run sim` and `npm run dev` with `.env.local` pointing to the simulator; sign-in requires a real Entra test registration (SIM-05) — if unavailable, use component previews/tests with mounted components and record the limitation.
2. Compare main view, modal (empty, with file, errors, submitting), and states A–F of `states.png`.
3. Apply UI-06 rules (no refresh button, white panel/input, no window frame, uniform label weight, "Traitée").
4. Keyboard pass: tab order, focus visible, Escape, dialog focus return.
5. Fix deviations in CSS/markup only; re-run component tests.

## Acceptance criteria

- [ ] Each mockup element checked; deviations fixed or justified by a written rule.
- [ ] Keyboard and screen-reader basics verified (roles `alert`/`status`, button names).
- [ ] Tests still pass.

## Verification

Manual comparison + `npm.cmd run test:run`.
