## Goal

Make the tracked configuration files describe exactly the keys of API spec §6.1, with empty values (`appsettings.json`) and placeholders (`appsettings.Development.json`), so that options binding (T-009) has a single, correct shape.

## Context (read first)

- API spec §6.1 (every key and default), DEC-04, HOST-05, §6.2.
- [ARB-023](ARB-023.md): default = remove `Azure:AppConfiguration`, `Azure:KeyVault`, `Azure:ServiceBus`, and move `Azure:Storage:BlobServiceUri` to `Storage:BlobServiceUri`.
- `klesia_api/docs/local-development.md` §3 (local overrides in git-ignored `appsettings.Local.json`).
- Current files: `src/WebApi/appsettings.json`, `appsettings.Development.json`, `appsettings.Local.json` (git-ignored — verify with `git check-ignore`; never commit it).

## Scope

- **In:** `appsettings.json`, `appsettings.Development.json`; verification that `appsettings.Local.json` is ignored.
- **Out:** code (T-009), real values (never committed).

## Plan of actions

1. `appsettings.json` (tracked, empty values): sections `ConnectionStrings:KlesiaDb`; `AzureAd` (`Instance` = `https://login.microsoftonline.com/`, `TenantId`, `ClientId`, `RequiredScope`); `Cors:AllowedOrigins` (empty array); `Storage` (`BlobServiceUri`, `ContainerName`); `Upload:MaxPdfSizeMb` = 10 (ARB-002 default); `DocumentIntelligence` (`Endpoint`, `ModelId`, `TimeoutSeconds` = 120, `ApiVersion` optional/omitted); `Extraction` (`MaxConcurrency` 2, `QueueCapacity` 100, `StaleAfterMinutes` 15, `SweepIntervalMinutes` 5); `AzureSignalR` (`Endpoint`, `HubName` = `demands`); `Logging` (keep); `AllowedHosts`.
2. Remove the `Azure` section (ARB-023 default). If ARB-023 is settled otherwise before this task starts, follow the decision.
3. `appsettings.Development.json`: placeholders of the form `<placeholder>` for every mandatory value (so T-009 rejects them), `Cors:AllowedOrigins` = `["http://localhost:5173"]`.
4. Confirm `appsettings.Local.json` is ignored by Git; if not, add it to `.gitignore` and stop: report to the user (possible secret exposure).
5. Update `docs/local-development.md` §3 example if keys differ (e.g., add `Storage`, `AzureSignalR`, `DocumentIntelligence` entries).
6. Attempt `dotnet build Klesia.sln` and record its result. The API scaffold has no `Program.cs` until T-010, so a `CS5001` failure at this stage is expected and is not a configuration failure; T-010 owns the passing full-solution build gate.
