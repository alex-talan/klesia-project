Verify that the SPA meets every acceptance criterion AC-01 to AC-56 that can run locally, the full build gate (AC-21) and the dependency audit (AC-42), and produce the AC coverage report.

- **In:** run all scripts; `/review-ac`; AC → test mapping; fix small gaps (larger ones → new task).
- **Out:** AC-57 (manual, T-088); live backend (T-077).

## Plan of actions

1. Run `npm run type-check`, `lint`, `format:check`, `test:run`, `audit`, `build` (AC-21) and the integration suite (T-070).
2. Run the `review-ac` skill; build the AC coverage table (AC id → test file/test name or *manual/environment-dependent*).
3. Confirm no suppressed lint rule or disabled check was added to pass.
4. `npm audit --omit=dev --audit-level=high`: no high/critical (AC-42) or documented exception.
