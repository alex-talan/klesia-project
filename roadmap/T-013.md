## Goal

Write the automated database constraint tests of API spec §3.6 that run **only** when `KLESIA_TEST_SQL_CONNECTION` points to a disposable published database, and are skipped (reported) otherwise. Running them for real is T-076.

## Context (read first)

- API spec §3.6 items 3–9, AT-15, AT-16, AT-49; §3.4 DDL; `docs/local-development.md` §6 (filter `SqlConstraintTests`, one transaction rolled back per test).

## Scope

- **In:** `tests/IntegrationTests/Database/SqlConstraintTests.cs` (+ helpers).
- **Out:** publishing the DACPAC, AT-17 (republish — manual, T-076).

## Plan of actions

1. A custom `[SqlFact]` (or `Skip` logic) that skips with the reason *"KLESIA_TEST_SQL_CONNECTION not set"* when the variable is absent.
2. Each test opens a `SqlConnection`, begins a transaction, does its inserts with Dapper parameters, asserts the `SqlException.Number` (547 check/FK violation, 2627/2601 unique violation), and rolls back.
3. Cases:
   - Named objects exist (query `sys.objects`/`sys.indexes`): every `PK_`, `FK_`, `AK_`, `CK_`, `DF_`, `IX_` of §3.4.
   - FK orphans: user→role, demand→user, demand→status, information→demand, formula→information (547).
   - Uniqueness: duplicate `Role.Code`, `Status.Code`, `User.UserUniqueId`, second `DemandInformation` for one demand fail; duplicate `Demand.GKNumber` **succeeds** (AT-16).
   - GK check: `gk260902-144743112`, `GX…`, letters, missing hyphen, 17 chars, embedded space fail; valid passes.
   - `BaeLink` not starting with `https://` fails; status code outside `pending`/`ok`/`fail` (incl. `OK`) fails.
   - Extraction checks (AT-49): SIREN 8 digits, SIRET not starting with SIREN, NIC 4 digits, zip 4 digits, NAF `5510z`, `Idcc` 10000, `ReferrerCode` −1, `CoveredAmount` 0, blank formula name fail; several formulas for one information succeed.
   - `Demand.CreatedAt` is filled by default (not null, close to `SYSUTCDATETIME()`).
   - Inactive user and user without demands can exist.
4. Test data uses invented values only (`integration-test` *Rules for test data*).

## Acceptance criteria

- [ ] Without the variable, all tests are skipped with an explicit reason and the suite is green.
- [ ] Each §3.6 item 3–9 case has a test; each test rolls back.
- [ ] No connection string or credential in the repository.
